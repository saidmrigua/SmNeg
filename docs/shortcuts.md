# Keyboard shortcuts

On Windows, `⌘` is `Ctrl`, `⌥` is `Alt` and `⇧` is `Shift`. Press `F1` in the app for the same list.

## Color (printer lights)

| Keys | Action |
|---|---|
| `Q / A` | Cyan + / − |
| `W / S` | Magenta + / − |
| `E / D` | Yellow + / − |

| `N` | Grey picker: click a neutral grey (sets C and Y); again on a lighter or darker grey to also correct highlights and shadows |
| `⇧N` | Clear the grey picks |
| `B` | Film-base picker: click the clear film between frames (rebate) |
| `⇧B` | Film base back to automatic detection |

## Density and tone

| Keys | Action |
|---|---|
| `↑ / ↓` | Density + / − |
| `⌥↑ / ⌥↓` | Contrast + / − |
| `⌘↑ / ⌘↓` | Saturation + / − |
| `T` | Tone profile: Natural → Flat → S Curve |
| `L` | Auto print on / off (Scientific engine; off = flat master) |
| `R` | Reset the frame |

## Image

| Keys | Action |
|---|---|
| `← / →` | Rotate |
| `M` | Mirror |
| `C` | Auto-crop (not on a frame with a manual crop) |
| `K` | Manual crop |
| `X` | Clipping preview |
| `P` | Pass: do not export |

## Zoom

| Keys | Action |
|---|---|
| `Z` | Zoom 100 % / fit |
| `Scroll wheel` | Smooth zoom |
| `Drag` | Pan the zoomed image |
| `Double-click · Esc` | Back to fit |
| `O` | Original before inversion |

## Navigation

| Keys | Action |
|---|---|
| `Space` | Grid ↔ enlarged view |
| `Enter · ⌘→` | Next frame |
| `⌘←` | Previous frame |
| `⇧⌘→ / ⇧⌘←` | Next / previous 6 frames |
| `Esc` | Back to the grid |

## Settings and export

| Keys | Action |
|---|---|
| `⌘C / ⌘V` | Copy / paste settings. In the Scientific engine the pasted frame is printed exactly like the copied one (same exposure, contrast and colour balance) |
| `⇧⌘V` | Release pasted print settings: the frame is metered on its own again |
| `H` | Hold: keep the settings for the next frames |
| `⌘Z / ⇧⌘Z` | Undo / redo |
| `⌘E` | Export |
| `F1 · ?` | This help |
